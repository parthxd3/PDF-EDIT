Offline AI writing assistant (XD3 PDF Editor)

Model: Qwen2.5-0.5B-Instruct by the Qwen team, Alibaba Cloud — Apache License 2.0 (LICENSE-Qwen.txt).
       ONNX conversion (4-bit weights, 16-bit embeddings: onnx/model_q4f16.onnx) from https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct
Runtime: Transformers.js 3.8.1 by Hugging Face, with ONNX Runtime Web (WebAssembly) — Apache License 2.0 (LICENSE-transformers.txt).

Everything here runs on the user's device. The model is only loaded the first time an AI button is used;
nothing is downloaded from the internet and no text is sent anywhere.
